# Tether for Visual Studio Code ⚓

> ADHD-vennlig Flowmodoro, automatisk kontekst-forankring og sømløs integrasjon med [Tether Desktop](https://github.com/Phrozenn1/tether-desktop).

## Funksjoner

- **⏱ Flowmodoro i Statuslinjen:** Følg med på flyten direkte nederst i editoren (`25:00 [FOKUS]`, `05:00 [PAUSE]`).
- **⚓ Automatisk Kontekst-forankring (Save-State):** Tether husker nøyaktig hvilken fil, linje og branch du jobbet på. Når du åpner Tether Desktop igjen, trykker du bare `Gjenoppta i VS Code 🚀`.
- **⚡ 5m Mikro-start:** Start en 5-minutters økt for å bryte dørstokkmila uten skyldfølelse.
- **🧠 Rask RAM-dump:** Parkér distraherende tanker med `Ctrl+Shift+P -> Tether: Rask RAM-dump` uten å bytte vindu.

## Snarveier og Kommandoer

Åpne Command Palette (`Ctrl+Shift+P` / `Cmd+Shift+P`):
- `Tether: Start / Pause Flyt`
- `Tether: 5m Mikro-start`
- `Tether: Rask RAM-dump`
- `Tether: Åpne Tether Desktop`
